# SQ Web Viewer Releases

Public, binary-only update repository for SQ Web Viewer.

- The application source is maintained in a separate private repository.
- The current automated release target is Linux x64.
- Installers, update metadata, checksums, and build manifests are attached to GitHub Releases; they are not committed to this branch.
- Releases are created as drafts by the protected source-repository workflow and are published only after review.

This repository intentionally contains no application source code or publishing credentials.
